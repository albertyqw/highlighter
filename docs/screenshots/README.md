# Screenshot assets

These images show Close Reader's development preview and are embedded in the repository's root README.

- `screenshots-and-notes.jpg`: area capture, saved caption, and image-note controls.
- `reading-and-notion.jpg`: article highlighting, metadata, and Notion import choices.
- `pdf-reader.jpg`: a real PDF rendered with PDF.js, highlighting, and page-anchored notes.

Article text and chart data are demonstration content. Notion responses and Chrome capture APIs were mocked during these local browser checks; the images do not show a live user workspace or expose connection credentials. The PDF example uses the public TraceMonkey sample distributed in Mozilla PDF.js's test documents: https://github.com/mozilla/pdf.js/blob/master/test/pdfs/tracemonkey.pdf.
